# Changesets

This folder is managed by `@changesets/cli`, which versions and publishes multi-package repos. Each pending
change is a short markdown file here; run `pnpm exec changeset` to add one. The full documentation is
[in the changesets repository](https://github.com/changesets/changesets), and the
[common questions](https://github.com/changesets/changesets/blob/main/docs/common-questions.md) page covers
the usual first problems.
