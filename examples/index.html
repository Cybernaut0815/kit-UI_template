Starters

Three ways to begin an on-brand app: hand it to your coding agent, copy the pattern, or run it.

Your coding agent

Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Antigravity, Windsurf and the other tools the skills CLI supports read the zha-ui skill. Install it in your project, then describe the app: the agent installs the package and composes on-brand pages.

npx skills add GitZHACODE/zha-ui

Or paste this to the agent: "Use the ZHA UI design system for everything visual in this project. Run npx skills add GitZHACODE/zha-ui -y, then read the installed zha-ui/SKILL.md and follow it."

The repository README lists where the skill lands for each tool, a manual route without npx and a note for Windows.

Vanilla starter

Plain HTML on the bundle, no build step. Open it, view source, copy the pattern: composition classes for layout, bundle classes for every component.

Under the hood

For builders: where the system lives and how to consume it.

Repository

Source, specs, issues and releases live in GitZHACODE/zha-ui. It needs a GitHub account on the org; everything else on this page works without one.

Open the repository on GitHub

Consume the system

@gitzhacode/zha-ui-css and @gitzhacode/zha-ui-tokens install straight from git: no token, no .npmrc, just your normal GitHub access. Add to package.json dependencies:

"@gitzhacode/zha-ui-css": "github:GitZHACODE/zha-ui#release/css"

They are also on GitHub Packages for registry installs; that route and the CI pipeline setup are in the repo README.

No GitHub access? This folder on the ES project share is a full mirror, refreshed on every commit - you are likely reading it right now.
