Foundation · Spec 1 of 2

An engineered register.

The ZHA token foundation, tuned for an engineered register: sharper corners, depth from borders, faster motion with a spring, a real tracking scale, and a denser rhythm. Everything below renders on the live ZHA tokens; each section's was → now table records what this refinement changed. Colour, type and the typology palette are unchanged.

Divider

.divider renders as a 1 px hairline using --border-subtle. Use <hr class="divider"> or any element with role="separator". Margin is --space-4 above and below.

Sidebar

.sidebar is a flex column of <a> links. The active item (a[aria-current="page"]) gets an --accent left bar via ::before. Each link wraps its text label in <span> so rail mode can hide it.

Data table

.data-table collapses borders, stretches inline to 100%. thead th is sticky + opaque bg-surface-1. .num right-aligns with tabular-nums. No zebra stripes; row hover uses bg-surface-2. Sort headers: a <button> inside th adopts the header typography automatically (sorting logic stays JS-deferred). Unit strings escape the uppercase transform with .th-unit.

18

Segmented control

.segmented is a pill-shaped track over native radio inputs. The checked label lifts off the track with bg-surface-1 + shadow-low, driven by :has(:checked). Keyboard = native radio arrow-key behaviour. No JS required.

19

Alerts

.alert carries intent via its 3 px inline-start border and icon colour; a tinted background fails AA on dark and brand surfaces. __icon is 16×16 (the inline icon step) and inherits the intent colour. __title is font-weight 600 + text-strong. Set role="status" (polite) or role="alert" (assertive) as needed.

Empty state

.empty-state is a centered flex column with space-12 vertical padding. __icon is a 48×48 rounded bg-surface-2 container - put an inline stroke SVG in currentColor inside it, never an emoji or image. h3 heading (text-strong, fs-h2) + p body (text-muted) + optional CTA. No container border.

22

View fade

.view-fade runs zha-view-fade: opacity 0→1 + translateY 8px→0 over motion-slow + ease-out. Apply when a new view enters the DOM (route changes, tab switches). The animation plays once and leaves the element fully visible.

23

Tabs

.tabs is the content-switching tab row - the input-like exclusive choice stays .segmented. One blessed selected treatment: text-strong + 2 px --accent underline, driven by aria-current="page" (valid on both <button> and <a> without the full role=tab/tablist + JS keyboard pattern). Hover lifts text to text-default.

24

Toggle & icon buttons

.btn.is-active (or aria-pressed="true") is the quiet persistent toggle: accent-subtle wash + 1 px --accent border; text stays text-strong (accent-family text fails AA at body size). .icon-btn is muted by default - utility icons are not brand decoration. .icon-btn--ghost drops the chrome but keeps the full hit target; it is the toolbar/chat form.

25

Tooltip & menu caret

.tooltip is paint-only - an inverse-surface box (near-ink on light, near-paper on dark), fs-small, 36ch max; positioning belongs to the consumer or the Anchor API. .menu__caret is the expandable-section chevron inside .menu rows: points right collapsed, rotates down when the row is aria-expanded="true". (The .menu below is inlined for display; real menus are [popover] elements.)
